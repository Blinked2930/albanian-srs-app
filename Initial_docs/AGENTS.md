# AI Agent Protocols for Albanian Lab

## Coding Style
- Use **Next.js Server Actions** for database mutations.
- Keep components small and minimalist.
- Use **Shadcn/UI** for buttons and inputs.

## The "Emmett" Rules (Mandatory)
- **Always ask me to copy and paste the current code for any file you are editing before you output the edited code.**
- Never show the Albanian translation in a "Drill" prompt.
- When generating sentences, ensure the grammar matches the metadata in `grammar_rules.json`.

## Data Handling
- Implement fuzzy matching for the "Phrase" category.
- Ensure the 'Usefulness' score manual override is checked before the standard SRS selection.
